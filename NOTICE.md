## Pac-Man experiment (`src/experiments/pacman/`)

This experiment is an **independent, non-commercial, educational recreation**
built to visualize classic game AI (ghost targeting heuristics, pathfinding,
and Pac-Man driver strategies). It is a fan homage and study piece.

- **PAC-MAN**, the Pac-Man character, the ghosts (Blinky, Pinky, Inky, Clyde),
  and the maze design are trademarks and/or copyrighted works of
  **Bandai Namco Entertainment Inc.**
- This project is **not affiliated with, endorsed by, sponsored by, or
  approved by** Bandai Namco Entertainment Inc. or any of its affiliates.
- No assets from any official Pac-Man release are used. All graphics are drawn
  procedurally on a canvas, and all sound effects are **synthesized at runtime
  with the Web Audio API** (no audio samples or recordings, and not transcriptions
  of Bandai Namco's musical compositions).
- All trademarks are used only nominatively, to identify the work being studied.

If you are a rights holder and have a concern about this educational use, please
[open an issue](https://github.com/baoloc7401/archive-of-experiments/issues/new)
and it will be addressed promptly.

## Minesweeper experiment (`src/experiments/minesweeper/`)

This experiment is an **independent, non-commercial, educational
implementation** of the classic Minesweeper puzzle, built to study no-guess
minefield generation and logic solvers.

- "Minesweeper" is a generic puzzle genre with a long history and many
  independent implementations; the name is used here only to describe the kind
  of puzzle.
- This project is **not affiliated with, endorsed by, sponsored by, or
  approved by Microsoft Corporation** or its "Microsoft Minesweeper" product,
  nor any other Minesweeper publisher.
- No assets from any official Minesweeper release are used. All graphics are
  original and drawn at runtime, and the board logic is implemented from
  scratch.

If you are a rights holder and have a concern about this educational use, please
[open an issue](https://github.com/baoloc7401/archive-of-experiments/issues/new)
and it will be addressed promptly.
